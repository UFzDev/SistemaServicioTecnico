# Sistema de Servicio Técnico

Proyecto Integrador de Gestión de Servicio Técnico desarrollado en C# (.NET Framework 4.8) con Windows Forms y Microsoft SQL Server bajo arquitectura N-Capas.

## Estructura del Repositorio

- **`01_Documentacion/`**: Diagrama Entidad-Relación (DER), Diccionario de Datos y manuales.
- **`02_SQL/`**: Scripts de base de datos numerados para ejecución secuencial.
- **`03_WindowsForms/`**: Solución de Visual Studio y proyecto Windows Forms (N-Capas: DAL, BLL, Vistas, Entidades).
- **`04_Evidencias/`**: Pruebas, evidencias de ejecución y capturas.
